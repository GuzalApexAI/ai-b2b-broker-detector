# 🛡️ AI B2B Broker & Fraud Detector

An enterprise-grade cyber-security AI protocol designed to mitigate counterparty risks, unverified middlemen, and fraudulent entities in global commodity B2B trading.

## 🌟 Core Features
- **IP & Domain Risk Analysis:** Evaluates the technical infrastructure and domain age of potential global suppliers.
- **Payment Terms Security Audit:** Automatically flags high-risk, non-corporate financial routing methods.
- **AI-Powered Fraud Synthesis:** Uses advanced semantic models to cross-reference supplier data against known B2B scams.

## 🛠 Tech Stack & Specifications
- **Core Engine:** Python Flask REST API Architecture.
- **AI Processing Layer:** OpenAI GPT-4 Security Logic integration.
- **Target Audience:** Commodity trading desks, global procurement houses, and logistics compliance officers.
